Let’s set up PlaneFuse

0 of 4 steps complete

Which computer are you using?

  1. 1

    Get the ready folder

    Download PlaneFuse for Mac

    This ZIP already contains the web interface and setup helper. It is not a frozen application.

    ↓ Download for macOS

    Latest fully tested main build · PlaneFuse-macOS-Apple-Silicon.zip

  2. 2

    Open the folder

    Double-click the downloaded ZIP

    Finder creates a PlaneFuse folder beside it. Move that folder somewhere convenient, such as Applications or Documents.

  3. 3

    Start PlaneFuse

    Right-click the launcher, then choose Open

    Inside the folder, right-click Launch PlaneFuse.command and choose Open. macOS asks for confirmation only on the first launch.

  4. 4

    Let it prepare

    Keep the small Terminal window open

    The first launch downloads PlaneFuse’s private Python environment and processing libraries. This can take 5–20 minutes. Your browser opens automatically when it is ready; later launches are much faster.

  1. 1

    Get the ready folder

    Download PlaneFuse for Windows

    This ZIP already contains the web interface and setup helper. PlaneFuse chooses NVIDIA acceleration or CPU automatically.

    ↓ Download for Windows

    Latest fully tested main build · PlaneFuse-Windows-x64.zip

  2. 2

    Open the folder

    Right-click the ZIP and choose Extract All

    Accept the suggested destination, then open the new PlaneFuse folder.

  3. 3

    Start PlaneFuse

    Double-click the PlaneFuse launcher

    Double-click Launch PlaneFuse.bat. If Windows asks, confirm that you want to run it. Keep the black setup window open.

  4. 4

    Let it prepare

    PlaneFuse finishes setup automatically

    The first launch downloads its private Python environment and processing libraries. Allow 5–20 minutes; NVIDIA systems may download more. Your browser opens when everything is ready.

02

The included uv executable creates a private environment without changing your system.

03
