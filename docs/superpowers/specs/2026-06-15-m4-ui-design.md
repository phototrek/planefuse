# FocusStack M4 Part 2 — Web UI Design

**Date:** 2026-06-15
**Status:** Approved (brainstorming)
**Depends on:** M4 Part 1 (server) — merged to `main` (commit `894d755`).
**Spec refs:** SPEC §2 (tech stack, layout), §9 (server/API), §10 (GUI screens), §13.2 (Playwright smoke), M4 milestone.

## Goal

Build the `ui/` Svelte frontend for FocusStack so a full **import → stack → view → export** cycle runs end-to-end in the browser against the Part 1 server, with the SPEC §13.2 Playwright smoke as the done-gate. Screens 1–4 + 6 (Project/Import, Stack setup, Queue/Progress, Viewer, Export). Retouch (screen 5) is M5; viewer compare-modes / depth overlay / blink / histogram are M6.

## Decisions (locked)

- **Framework:** SvelteKit + `@sveltejs/adapter-static` in SPA mode (`ssr = false`, `prerender` off, `fallback: 'index.html'`). Svelte 5 runes, TypeScript, Vite.
- **Build target:** Vite/adapter output → `server/src/focusstack_server/static/` — exactly where Part 1's `create_app` already mounts `StaticFiles(directory=ui_dir, html=True)`. No Node in production.
- **Viewer scope:** basic tiled deep-zoom only (wheel-zoom on cursor, drag-pan, F=fit, Z=100%). Compare modes/histogram deferred to M6.
- **E2E:** Playwright smoke included — it is the M4 acceptance gate.
- **Aesthetic:** built with the **frontend-design skill** for a distinctive, production-grade dark tool UI, within SPEC §10 constraints (near-black panels, single accent color, every control tooltipped, keyboard-first).
- **UI state:** persisted via the server (`PATCH /api/projects/{id}/ui-state`), never localStorage (SPEC §10). App boots to the Project screen; opening a project restores its `ui_state` (screen, selections, viewer position).

  src/
    app.html
    routes/

### Server additions (additive to Part 1)

1. **SPA fallback** — a FastAPI catch-all that returns `index.html` for any non-`/api`, non-`/ws`, non-static path, so a refresh on `/viewer` (client-routed) doesn't 404. `StaticFiles(html=True)` only serves `/` and exact files. Mounted last, after all routers.
2. **Frame thumbnail endpoint** — `GET /api/projects/{id}/frame-thumb?path=…` → small JPEG (e.g. long edge 256). The filmstrip needs thumbnails and the browser can't decode 16-bit TIFFs; reuses the Pillow path from `tiles.py`. Validates the path belongs to the project's frames.
3. No global "active project" persistence — avoided by booting to the project list.

Both endpoints get pytest coverage (`tests/server/`), keeping ruff/mypy/pytest green.

## Components & data flow

- **Boot:** `GET /api/system` (device banner) + `GET /api/projects` (list).
- **Project/Import (`/`):** create project (folder browser → `GET /api/fs/list`); open → `GET /api/projects/{id}`; import → `POST /frames/scan` (validation report drives badges); filmstrip thumbnails via the new thumb endpoint; `POST /frames/auto-group` → proposed groups for confirmation.
- **Stack setup (`/stack`):** parameter forms generated from `GET /api/algorithms` metadata (name/label/type/default/min/max/choices/tooltip); alignment toggle + settings; smart-selection toggle; preset save/load (`GET/POST/DELETE /api/presets`); "Stack" → `POST /api/projects/{id}/jobs {type:"stack", params}`; "Stack all groups" enqueues one job per group.
- **Queue/Progress (`/queue`):** `GET /api/jobs` list + live updates from `/ws` (filter by `job_id`): per-job progress bar, live log line, cancel (`DELETE /api/jobs/{id}`), history with params (re-run).
- **Viewer (`/viewer`):** on a finished stack, `POST /api/projects/{id}/viewer/register` the result `image_id` → returns `levels`; `DeepZoom.svelte` requests `GET /api/viewer/{image_id}/tile/{z}/{x}/{y}`.
- **Export (`/export`):** format/bit-depth/quality, naming template + live preview, destination, "also export depth map" → `POST /api/projects/{id}/export`; watch to `done`.
- **Persistence:** `PATCH /api/projects/{id}/ui-state` on screen/selection/viewer changes; restored on open.

### Error handling

- `api.ts` maps non-2xx `{error, detail}` JSON to a thrown typed error; UI surfaces via toast (transient) or inline (form/validation).
- `ws.ts` auto-reconnects on drop; queue falls back to polling `GET /api/jobs/{id}` if the socket is down.
- Device banner shows cpu/cuda/mps and free memory from `/api/system`.

## Testing & gates

- **Playwright smoke** (`ui/tests/smoke.spec.ts`): a fixture launches `focusstack-server` against a temp data dir and pre-generates a small synthetic stack on disk (Python helper reusing `tests/synthetic/generate.py`). Playwright `webServer` serves the built UI through the server. Steps: create project → scan → run PMax → wait job `done` → open viewer, assert a tile renders → export → assert output file exists.
- **Gates:** `npm run check` (svelte-check) clean; `npm run build` populates the server static dir; `npx playwright test` green; `uv run pytest` + `uv run ruff check .` + `uv run mypy engine/src server/src` still green.
- **Svelte MCP server** used during implementation (mandatory) for docs + component autofixing.
